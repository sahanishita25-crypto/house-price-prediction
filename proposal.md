\# Project Proposal: House Price Prediction Using Linear Regression



\## 1. Research Question



Can house sale prices be predicted using property features such as living area, overall quality, garage size, and year built?



\## 2. Project Objective



The objective of this project is to develop a Machine Learning model using Linear Regression to predict residential house sale prices.



\## 3. Dataset Information



\- Dataset Name: House Prices - Advanced Regression Techniques

\- Dataset Source: Kaggle

\- Dataset Link: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

\- Original Dataset Research: De Cock (2011)

\- Target Variable: SalePrice

\- Technique: Linear Regression



\## 4. Literature Review: Two Existing Sources



\### Source 1



Zhou, C. (2024). Prediction of second-hand house prices in Ames city based on data mining.



Link: https://doi.org/10.54254/2755-2721/46/20241300



This research used the Ames Housing Dataset and compared seven Machine Learning models, including Linear Regression, Ridge Regression, Random Forest, and Neural Networks. The study found that RidgeCV performed particularly well.



\### Source 2



Ames Housing Dataset, Adarsh Sahani, and Kundan Paswan (2025). House Price Prediction Using Linear Regression.



Link: https://doi.org/10.63503/c.acset.2025.20



This research used Linear Regression to predict house prices using the Ames Housing Dataset. It reported an R² score of 0.82 and discussed data cleaning and model evaluation.



\### Research Gap



Based on these studies, this project will focus on implementing a simple Linear Regression model and understanding how different house features influence predicted sale prices.



\## 5. Methodology



1\. Collect the public dataset.

2\. Explore and understand the data.

3\. Handle missing values.

4\. Select relevant features.

5\. Split the dataset into training and testing sets.

6\. Train a Linear Regression model.

7\. Evaluate the model using MAE, MSE, RMSE, and R² score.



\## 6. Expected Outcome



The expected outcome is a trained Linear Regression model that predicts house sale prices and provides an understanding of the relationship between house features and sale prices.
